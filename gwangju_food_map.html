광주, 한 끼의 발견

경기도 광주시 음식점 · 카카오 지도 검색

‘맛집’ 키워드 검색 서비스입니다. 별점 순위나 추천 인증을 뜻하지 않습니다. 지역·음식 종류는 검색어에 반영됩니다.

JavaScript 키를 설정하면 검색할 수 있습니다.
    처음 실행하는 방법
    1. 카카오디벨로퍼스에서 앱을 만들고 [카카오맵 → 사용 설정]을 ON으로 설정합니다.
    2. JavaScript 키의 SDK 도메인에 http://localhost:8000 을 등록합니다.
    3. 아래 입력란에 JavaScript 키를 입력하거나 파일의 KAKAO_JAVASCRIPT_KEY를 수정합니다.
    4. 파일이 있는 폴더에서 py -m http.server 8000 --bind 127.0.0.1을 실행하고 http://localhost:8000/gwangju_food_map.html 로 접속합니다.

    입력한 키는 이 페이지에서만 사용하며 저장하지 않습니다. REST API 키나 Admin 키를 넣지 마세요. 키 변경·재시도는 새로고침 후 진행하세요.

    지도 연결을 기다리고 있어요

    왼쪽 ‘처음 실행하는 방법’에 따라 키를 설정하세요.

    검색 결과는 카카오에서 실시간으로 가져오며, 주소가 경기도 광주시인 음식점만 표시합니다.
