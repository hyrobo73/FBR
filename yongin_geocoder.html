용인시 맛집 주소 → 경도·위도

업로드한 음식점 120개 내장 · WGS84(EPSG:4326) · UTF-8 BOM CSV 다운로드

  1. 카카오 앱에서 카카오맵 사용 설정을 켜고, JavaScript SDK 도메인에 http://localhost:8000을 등록하세요.
  2. 이 파일이 있는 폴더에서 py -m http.server 8000 --bind 127.0.0.1 실행 후 http://localhost:8000/yongin_geocoder.html로 접속하세요.
  3. 키 입력 → 연결 → 좌표 변환 → CSV 다운로드 순서로 진행하세요.

주소만 카카오 주소 검색 서비스로 전송합니다. 주소 검색 결과가 유일하고 용인시 주소인 경우 좌표를 기록합니다. 복수 후보·검색 실패는 좌표를 비워두고 상태를 표시합니다. 좌표는 건물/필지 위치이며 음식점 영업 여부를 검증하지 않습니다.

‘확인 필요’ 항목은 아래 변환용 주소를 수정하고 다시 실행하세요. 원본 주소는 CSV에 그대로 보존됩니다. 변환 결과는 새로고침하면 사라지므로 먼저 다운로드하세요.
